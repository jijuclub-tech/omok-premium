## Vercel에 배포하기 (추천)

1. https://vercel.com 에 가서 GitHub로 로그인
2. New Project → Import Git Repository → `jijuclub-tech/omok-premium` 선택
3. Deploy 버튼 클릭 (static site이라 추가 설정 필요 없음)

완료 후 생성된 URL로 접속하면 됩니다.
